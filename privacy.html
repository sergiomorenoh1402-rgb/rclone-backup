Privacy policy

Last updated: November 21, 2026

This app is a personal rclone setup used by a single person (the owner) to back up their own files to their own Google Drive.

  • It only accesses the owner's own Google Drive, to upload, update and list backup files.
  • It does not collect, store, share or sell any data about anyone else.
  • No data is sent to any third party. Files go directly from the owner's computer to the owner's Google Drive.
  • Google user data is used only to provide this backup, in line with the Google API Services User Data Policy, including the Limited Use requirements.

The owner can revoke access at any time at myaccount.google.com/permissions.
